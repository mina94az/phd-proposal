# PhD proposal-defense LaTeX project

This project is an initial written proposal for ENCS 8511 at Concordia University. Its structure follows Concordia's proposal-writing guidance and the ENCS 8511 requirement for a critical literature review, detailed research plan, and expected milestones.

## Build

From this directory, run:

```bash
latexmk -pdf main.tex
```

Clean generated files with:

```bash
latexmk -c
```
